# Rodent Colonies (`rodent_colonies`)

Мод-симулятор колоний мышей и крыс для **Minecraft Java Edition 1.20.1 (Fabric)**.

> **Главный принцип:** *мир меняется, но не исчезает*. Ни один блок не появляется «из воздуха» (`поставлено ≤ добыто − потеряно + захвачено`), ни один участок не превращается в пустошь, а любую правку колонии можно откатить встроенным журналом изменений.

---

## Возможности

- **Два вида грызунов с разными ролями:**
  - **Мышь** (`rodent_colonies:mouse`): 6 HP, хитбокс `0.4 × 0.5`, быстрая, уносит семена и мелкие плоды, в бою кусает и отскакивает, избегает крыс.
  - **Крыса** (`rodent_colonies:rat`): 10 HP, хитбокс `0.6 × 0.7`, выносливее, носит любую еду (включая овощи, хлеб, мясо и сено), держит строй, охотится на мышей и защищает вход.
- **Честная стройка нор без блоков из воздуха:**
  - Грызуны сами добывают мягкие породы, валежник, сено и листву в радиусе 24 блоков, несут их «в зубах» к норе и строят вход с холмиком, камеры `3×3×3` и `5×3×3`, отнорки и кладовые.
  - Аварийные пробки при протечке воды или лавы имеют приоритет выше любой стройки.
- **Бережное отношение к миру и постройкам игрока:**
  - Уважаются `mobGriefing` и `doMobSpawning`.
  - С грядки снимается не более 30% зрелых растений, последнее зрелое растение и сам блок `farmland` никогда не ломаются, а оброненные при переноске семена дают новые всходы.
  - Неприкосновенны ванильные структуры (деревни, шахты, крепости), блоки с `BlockEntity` (сундуки, бочки, печи, кровати), руды, обсидиан, бедрок и постройки игрока.
  - Трёхуровневый бюджет изменений (400 блоков/день на колонию, 100 блоков и ≤15% мягких пород на чанк за всё время, ≤8 блоков/с на измерение).
- **Войны колоний и коалиции:**
  - Эскалация: `Нейтралитет → Напряжение → Набеги → Война → Захват → Перемирие`.
  - Война расходует население, а не мир: потери ограничены ≤2 особями за стычку, победитель захватывает уже вырытую нору как филиал, а выжившие 3+ беглеца могут основать новую колонию.
  - Две колонии одного вида могут объединиться в **коалицию** против общего врага, который сильнее на 30%+, координируя совместные отряды до 8 бойцов.
- **Природные события:**
  - Прорастание семян и восстановление грядок, рыхление почвы и перенос осадка у воды.
  - Временное локальное затопление и выгорание подлеска (по умолчанию **выключены**, стволы деревьев никогда не сгорают).
- **Журнал изменений и откат:**
  - Кольцевой буфер `SavedData` на 50 000 записей (30 игровых дней), команды `/rodentcolonies rollback`, `/rodentcolonies stop` и режим `safeMode`.

## Требования и сборка

- **Minecraft:** `1.20.1`
- **Fabric Loader:** `>= 0.19.5`
- **Fabric API:** `0.92.12+1.20.1`
- **Java для игры:** Java 17+
- **JDK для сборки Gradle / Loom:** JDK 21 (код компилируется с `--release 17`)

```bash
./gradlew build
```

Готовый файл мода появится в `build/libs/rodent_colonies-0.1.0.jar`.

## Команды администратора и отладки

| Команда | Описание |
| --- | --- |
| `/rodentcolonies info [id]` | Общая сводка лимитов, колоний, войн и MSPT либо подробная карточка колонии `id` |
| `/rodentcolonies reload` | Перезагрузка `config/rodent_colonies.json` |
| `/rodentcolonies debug anim <mouse\|rat> <state>` | Спавн особи с замороженной анимацией (`idle`, `sniff`, `groom`, `walk`, `run`, `eat`, `place`, `alarm`, `sleep`, `attack`, `hurt`, `death`, `baby`) |
| `/rodentcolonies debug spawn <mouse\|rat> [n]` | Ручное создание колонии из `n` особей |
| `/rodentcolonies journal` | Сводка изменённых блоков по колониям и природным событиям |
| `/rodentcolonies rollback <colonyId> [n]` | Откат последних `n` правок колонии (включая отмену захвата чужой норы) |
| `/rodentcolonies stop` | Аварийная остановка/возобновление любых изменений мира модом |
| `/rodentcolonies war list` | Список всех активных конфликтов и ступеней эскалации |
| `/rodentcolonies war end <a> <b>` | Принудительное перемирие между колониями `a` и `b` |
| `/rodentcolonies coalition list` | Список активных коалиций |
| `/rodentcolonies coalition end <a> <b>` | Принудительный роспуск коалиции между `a` и `b` |
